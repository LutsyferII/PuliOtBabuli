# ПулиОтБабули 🎯

Учебный интернет-магазин патронов, написанный на чистом PHP + MySQL + vanilla JS/CSS.

> ⚠️ Это учебный проект 2022-го года, созданный в процессе изучения веб-разработки. Код содержит исторические артефакты эпохи (включая нецензурную лексику в комментариях и названиях переменных).

## 🚀 Стек технологий

- **Backend:** PHP (без фреймворков)
- **База данных:** MySQL
- **Frontend:** HTML, CSS, vanilla JavaScript
- **Библиотеки:** jQuery (для AJAX)

## ✨ Основные возможности

### Каталог товаров
- Пагинация (12 товаров на страницу)
- Фильтрация по калибрам (7.62x39, 5.45x39, 5.56x45)
- Карточки товаров с изображениями
- Детальная страница товара

### Поиск
- Полнотекстовый поиск по названию
- Сохранение поискового запроса в сессии
- Пагинация результатов

### Корзина
- Добавление/удаление товаров
- Изменение количества
- Подсчёт итоговой стоимости
- Мини-корзина в шапке сайта (виджет)
- AJAX для обновления корзины без перезагрузки

### Архитектура
- **Собственный шаблонизатор** (класс `Page`)
- Разделение на компоненты: `header.inc`, `foot.inc`
- Централизованное управление стилями и скриптами
- Модульная структура страниц


## 🗄️ База данных

Структура таблицы `ammo`:
- `ammoid` — ID товара
- `nazv` — название
- `caliber` — калибр
- `typ` — тип
- `mass` — масса
- `typeammo` — тип патрона
- `maker` — производитель
- `price` — цена
- `type` — блок
- `url_img` — путь к изображению
